Grammaire A1
Formes plurielles
Un chien - deux chiens.
Un chat - trois chats.
Un enfant – quatre enfants.
Une voiture – plusieurs voitures.
La maison est ancienne. Les maisons sont anciennes aussi.
Une femme parle. Les femmes parlent.
Un homme travaille. Les hommes travaillent.
Un livre est posé sur la table. Les autres livres sont là aussi.
Une ville est grande. Plusieurs villes sont grandes.
Mon copain vient. Mes amis viennent aussi.
Une lampe brille. Les lampes brillent.
Une pomme est rouge. Les pommes sont rouges.
Une chaise est neuve. Les chaises sont neuves.
Un oiseau chante. Les oiseaux chantent.
Une fleur est belle. Les fleurs sont belles.
Un élève apprend. Les élèves apprennent.
Un train roule vite. Les trains roulent vite.
Une tasse est sur la table. Les tasses sont là.
Une fenêtre est ouverte. Les fenêtres sont ouvertes.
Un des professeurs est gentil. Les professeurs sont gentils.
Les appartements sont chers.
Un mot est important. Les mots sont importants.
Un enfant joue. Deux enfants jouent aussi.
L'une achète des pommes. Les autres achètent des oranges.
De nombreux invités arrivent aujourd'hui.
J'achète trois rouleaux et deux journaux.
Les livres et les cahiers sont posés sur la table.
